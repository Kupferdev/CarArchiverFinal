# Car Service Archiver — v34.5 düzeltme paketi (kaynak kod)

v34.5 kaynak paketi temel alınmıştır.

## Yapılanlar
- TypeScript TS6133: iki kullanılmayan repository import'u, App'te kullanılmayan `t`, SettingsPage'deki React default import'u temizlendi.
- ESLint `no-control-regex`: PDF dosya adındaki kontrol karakterleri Unicode/ASCII karakter koduyla güvenle temizleniyor; yasak karakterler hâlâ filtreleniyor.
- React Hooks: CarForm, CarProfile, ServiceProfile, CustomerProfile effect/memo bağımlılıkları ele alındı. CarForm'da ilk veri yüklemesi artık dil değiştiğinde seçili yakıt/kasa çevirilerini ezmiyor.
- Genel arayüz ölçeği: %50–%150, %100 varsayılan. Önceki geçersiz kayıtlı ölçekler güvenli aralığa sıkıştırılıyor.
- Gereksiz metin seçimi: uygulama navigasyonu, listeler ve kartlar seçilemez; input/textarea/düzenlenebilir alanlar seçilebilir olmaya devam ediyor.
- Ayarlar dişlisi sekme şeridinde kutusuz/çerçevesiz görünümde.
- Sabitleme: yeni kayıt/düzenleme formlarında pin simgesi ve sağ tık sabitleme seçeneği yok. Tab store işlemi de sabitlemeyi engelliyor. Geçmişte kayıtlı form pinleri açılışta geri yüklenmez. Liste, profil ve Ayarlar sabitlemeleri korunur.
- Windows üst çerçeve için tema renkli sürükleme yüzeyi CSS'i pekiştirildi; dış işletim sistemi çerçevesindeki son pikseller Windows yönetiminde olabilir.

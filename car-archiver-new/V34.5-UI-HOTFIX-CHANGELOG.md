# Car Service Archiver — v34.5 UI Hotfix 2

Based on the verified v34.5 Hotfix source.

## Changes

- Disabled native text selection for non-editable UI across the whole app, including startup screens, dashboard, menus, table contents, tabs and header. Real text inputs, textareas and editable content remain selectable.
- Disabled native dragging of the header SVG logo to Windows desktop. The logo still navigates to Home when clicked; titlebar dragging is separate.
- Made Settings gear borderless by default and gave it a square (`border-radius: 0`) hover background, plus visible keyboard focus outline.
- Improved native Windows titlebar/theme alignment: when the user changes theme, Electron now saves the selected native titlebar palette; subsequent BrowserWindow creations start with the saved palette instead of hardcoded navy. The 30px draggable renderer chrome uses the exact `--bg-panel` token as the header.

## Not verified here

- Full `npm run verify`, Electron runtime, and native Windows composition: node_modules are not available here.
- Actual Windows titlebar/border color matching is OS-dependent, and must be visually retested on Windows across all four themes. This patch fixes saved startup color and matching renderer token but does not claim control over every OS-drawn border pixel.
